## Audio and recording

- Added microphone noise suppression with RNNoise and adjustable Speex processing.
- Enabled RNNoise by default for new and existing installations. Later user choices are preserved.
- Added a microphone threshold with smooth transitions.
- Added live output meters after microphone filtering and volume adjustment.
- Fixed empty audio tracks when both audio sources are disabled by writing a silent AAC track.

## Interface

- Aligned controls, sliders and value fields across both settings panels.
- Moved microphone filters beside the microphone switch.
- Added a recording badge to the taskbar icon.
- Allowed the window to appear in screen sharing when window hiding is disabled.
- Centered the filename field vertically and updated the English and Russian screenshots.

Windows 10/11 x64. Download the executable to run directly, or the ZIP package with license notices.
